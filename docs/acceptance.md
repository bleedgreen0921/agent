# Agent 目标、证据与工具验收

新 Run 使用图 v5、状态 v3、提示 v4、Manifest schema 6。恢复契约版本 2；实际图记录与调用回执仍使用协议 2。历史终态不补造验收结果。输入预算、分组最终核验和最新迁移见 [上下文与保留协议](context-and-retention.md)。

目标分析只使用当前请求的原始 task。会话记忆、文献、工具结果和历史摘要均为观察数据，不提供新目标或副作用授权。计划关联需求 ID，步骤返回后仍需独立检查 completion_condition；不满足或无法确定时停止后续步骤，发布 partial。没有自动重新规划、修正或外部调用重放。

步骤间传递结构化的事实、来源、假设、条件、未解决事项和实际交付。文献来源引用使用 Python 字符位置和原文片段；实验结果沿用 JSON 计算产物及其方法、来源摘要与 synthetic 标识。未核实内容不会自动成为已证实事实。

工具调用按模型输出批次进行独立意图检查。只读科研探索可以获准；任何动作被拒绝或不确定时整批不执行。工具入口核对实际工具名称、参数摘要和触发调用，再经过容量等待和持久执行权检查。

副作用工具需声明 `ToolIntentSpec(operation, effect_fields)`。调用方必须在 Run 或会话轮次请求中提交显式授权。例如测试工具的请求：

```json
{
  "task": "将研究摘要追加到 research 笔记本",
  "mode": "react",
  "tool_authorizations": [{
    "tool_name": "synthetic_write",
    "operation": "append",
    "exact_arguments": {"target": "research"},
    "max_calls": 1
  }]
}
```

该工具仅存在于测试 provider，生产默认工具没有真实副作用。所有声明的 effect_fields 必须给出具体标量值，不支持通配范围。授权次数与工具调用预留同事务登记；提交未知时不得执行。明确授权不替代意图关联检查。授权不继承到下一轮次。

模型预算仍为 16 次，其中两次分别保留给最终生成与最终验收，其余检查和业务调用共用 14 次。独立检查复用配置的模型，但使用单独上下文且没有工具能力，遵守原期限、限流和调用账本。

最终候选采用结论与交付块。验收核对原始任务、需求列表、完整候选和原始证据；代码只渲染通过的块，不直接发布候选 answer 字符串。证据不支持、冲突、条件缺失、验收不可用或未完成需求均导致 partial。确定性实验规则不能被模型判断覆盖。

公开结果增加可选 acceptance 报告；旧结果该字段为空。验收报告、正文、引用、关联摘要任务和终态原子提交。图内验收输出有真实 checkpoint 回执；最终生成和最终验收位于图外，中断后遵守未知中断规则，不自动重新生成。

语义验收是模型辅助评估，不是正确性的数学证明，也不是工具代码沙箱。持久执行权、结构规则和显式授权仍由代码强制执行。

升级时排空旧 Worker，备份个人数据库，运行既有增量迁移与授权流程，再启动新 API/Worker。仅没有 Manifest、尚未开始的排队任务升级；已开始的旧图不转换。回退使用匹配代码和备份。
